# 출처와 라이선스

## 캐릭터
응시자 캐릭터(머리·얼굴·옷·소지품)는 모두 `index.html` 안의 코드로 직접 만든 3D 도형과 캔버스 그림입니다.
외부 3D 모델 파일을 쓰지 않으므로 별도의 이용 조건이 없습니다.

## 라이브러리
- three.js 0.160.0, MIT License (`lib/LICENSE-three.txt`)
  - `lib/addons/utils/BufferGeometryUtils.js` (three.js 애드온, 같은 라이선스)
